# E-Commerce_Sales_Dashboard_Microsoft_Excel

E-Commerce Sales & Customer Insights Dashboard | Microsoft Excel
-

Project Overview
-
The E-Commerce Sales & Customer Insights Dashboard is an interactive Excel-based business analytics project developed to analyze sales performance, customer behavior, order status, regional sales, and sales channel performance.

The dashboard transforms raw e-commerce data into meaningful visual insights using PivotTables, PivotCharts, slicers, and interactive dashboards, helping businesses understand sales trends and customer purchasing patterns.

Project Objectives
-
Analyze overall sales and order performance.
Understand customer purchasing behavior by gender and age group.
Compare sales performance across different sales channels.
Identify top-performing states based on sales.
Analyze order status such as delivered, cancelled, returned, and refunded.
Identify important sales and customer trends for data-driven decision-making.

Key Features
-
Created interactive slicers for:
-
Month,
Sales Channel,

Developed Order vs. Sales column charts to compare order volume and sales performance.
Created Male vs. Female customer analysis using pie charts.

Developed Order Status analysis for:
-
Delivered,
Cancelled,
Returned,
Refunded,
Created a Top 5 States by Sales bar chart to identify high-performing regions.
Developed Age Group vs. Gender analysis to understand purchasing behavior across different customer segments.
Created Sales Channel analysis to compare performance across platforms such as Amazon and Flipkart.
Used interactive dashboard elements to make data exploration simple and user-friendly.

Dashboard Analysis
-
The dashboard provides insights into:
-
Sales Performance: Analyze sales and order trends over different months.
Customer Behavior: Compare purchasing patterns based on gender and age groups.
Regional Performance: Identify the states generating the highest sales.
Order Status: Monitor delivered, cancelled, returned, and refunded orders.
Sales Channels: Compare orders and sales generated through different e-commerce platforms.
Product Categories: Analyze performance across different product categories.

Data Analysis Process
-
Data Preparation – Organized and prepared the raw e-commerce dataset for analysis.
Data Cleaning – Checked and handled data inconsistencies to improve data quality.
Data Analysis – Used Excel PivotTables to summarize sales, orders, customers, and other business metrics.
Data Visualization – Created PivotCharts and other visualizations to represent important trends.
Dashboard Development – Added slicers and interactive elements to enable dynamic filtering.

Business Insights
-
The dashboard helps identify high-performing sales channels, top-performing states, customer purchasing patterns, popular product categories, monthly sales trends, and order fulfillment performance. These insights can support businesses in improving sales strategies, understanding customers, and making data-driven decisions.
